# Pengujian Blackbox Fitur Dashboard Admin

Dokumen ini berisi skenario pengujian blackbox untuk fitur dashboard admin pada aplikasi Rekofin UI.

| No  | Bentuk Pengujian                                                                                                         | Hasil yang Diharapkan                                                                                                                                                   | Hasil Pengujian                                                                                    | Kesimpulan |
| --- | ------------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------- | ---------- |
| 1   | Admin dengan token valid membuka halaman dashboard admin                                                                 | Sistem menampilkan halaman dashboard admin dengan komponen utama: sapaan admin, kartu statistik, grafik kategori, grafik hasil konsultasi per bulan, dan menu pintasan. | Berhasil sesuai hasil yang diharapkan. Seluruh komponen utama dashboard tampil.                    | Valid      |
| 2   | Dashboard admin memuat data saat API /api/admin/dashboard merespons sukses                                               | Sistem menampilkan data statistik total pengguna, total aturan, total fakta/pertanyaan, total konsultasi, serta data grafik sesuai respons API terbaru.                 | Berhasil sesuai hasil yang diharapkan. Data dashboard dan grafik tampil sesuai API.                | Valid      |
| 3   | Data chart consultation_result_categories kosong                                                                         | Grafik kategori tidak ditampilkan (kosong/hilang) saat data kosong, namun halaman dashboard tetap stabil dan dapat digunakan.                                           | Berhasil sesuai hasil yang diharapkan. Halaman tetap stabil saat data kategori kosong.             | Valid      |
| 4   | Data chart consultation_result_by_month kosong                                                                           | Grafik hasil konsultasi per bulan tidak ditampilkan (kosong/hilang) saat data kosong, namun komponen lain tetap berjalan normal.                                        | Berhasil sesuai hasil yang diharapkan. Halaman tetap stabil saat data per bulan kosong.            | Valid      |
| 5   | Admin membuka dashboard dengan data statistik bernilai 0 (belum ada data)                                                | Sistem menampilkan nilai 0 pada seluruh kartu statistik tanpa menampilkan informasi yang salah.                                                                         | Berhasil sesuai hasil yang diharapkan. Semua nilai statistik ditampilkan 0 dengan benar.           | Valid      |
| 6   | Admin menekan masing-masing menu pintasan di dashboard (Kelola Pengguna, Fakta, Sumber, Kesimpulan, Rekomendasi, Aturan) | Setiap menu pintasan mengarahkan ke halaman manajemen admin yang sesuai dengan menu yang dipilih.                                                                       | Berhasil sesuai hasil yang diharapkan. Seluruh menu pintasan mengarah ke route yang benar.         | Valid      |
| 7   | Nilai username tersedia di localStorage saat dashboard dibuka                                                            | Sistem menampilkan sapaan Selamat datang kembali dengan nama admin sesuai nilai username pada localStorage.                                                             | Berhasil sesuai hasil yang diharapkan. Nama admin tampil sesuai data localStorage.                 | Valid      |
| 8   | Nilai username tidak tersedia di localStorage saat dashboard dibuka                                                      | Sistem tetap menampilkan sapaan default dengan nama Admin dan tidak menyebabkan error pada tampilan.                                                                    | Berhasil sesuai hasil yang diharapkan. Sapaan default Admin tampil normal.                         | Valid      |
| 9   | Pengguna tanpa token atau dengan token kedaluwarsa mengakses route protected dashboard admin                             | Sistem menghapus token lokal, menolak akses halaman protected, lalu mengarahkan pengguna ke halaman login.                                                              | Berhasil sesuai hasil yang diharapkan. Pengguna tidak dapat mengakses dashboard tanpa token valid. | Valid      |
| 10  | Pengguna dengan token role USER mencoba memanggil API dashboard admin                                                    | Sistem menolak akses endpoint admin (unauthorized/forbidden), sesi dibersihkan di client, dan pengguna diminta login ulang.                                             | Berhasil sesuai hasil yang diharapkan. Akses endpoint admin ditolak untuk role USER.               | Valid      |
| 11  | Terjadi gangguan jaringan/server saat pengambilan data dashboard admin                                                   | Halaman tidak crash, komponen utama tetap muncul, dan aplikasi tetap dapat digunakan setelah proses loading selesai.                                                    | Berhasil sesuai hasil yang diharapkan. Aplikasi tetap stabil saat terjadi error API dashboard.     | Valid      |
