# Pengujian Blackbox Fitur User Profile

Dokumen ini berisi skenario pengujian blackbox untuk fitur user profile pada aplikasi Rekofin UI.

| No  | Bentuk Pengujian                                                                                                          | Hasil yang Diharapkan                                                                                                                                               | Hasil Pengujian                                                                                                | Kesimpulan |
| --- | ------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------- | ---------- |
| 1   | Pengguna role USER membuka halaman profil dengan token login valid                                                        | Sistem menampilkan halaman profil berisi data user (fullname, username, email, gender) dan section ubah password.                                                   | Berhasil sesuai hasil yang diharapkan. Data profil dan form ubah password tampil.                              | Valid      |
| 2   | Halaman profil dimuat saat API get profil berhasil                                                                        | Sistem menampilkan nilai data profil sesuai data dari server.                                                                                                       | Berhasil sesuai hasil yang diharapkan. Informasi profil tampil sesuai respons API.                             | Valid      |
| 3   | Halaman profil dimuat saat API get profil gagal                                                                           | Sistem menampilkan notifikasi gagal (modal error) tanpa menyebabkan halaman crash.                                                                                  | Berhasil sesuai hasil yang diharapkan. Notifikasi error muncul dan aplikasi tetap stabil.                      | Valid      |
| 4   | Pengguna menekan tombol Edit Profil                                                                                       | Sistem mengaktifkan mode edit, field profil dapat diubah, serta tombol Simpan Perubahan dan Batal tersedia.                                                         | Berhasil sesuai hasil yang diharapkan. Field dapat diedit dan tombol aksi tampil.                              | Valid      |
| 5   | Pengguna mengosongkan fullname lalu menekan Simpan Perubahan                                                              | Sistem menolak submit dan menampilkan pesan validasi bahwa nama lengkap wajib diisi.                                                                                | Berhasil sesuai hasil yang diharapkan. Validasi fullname tampil dan data tidak dikirim.                        | Valid      |
| 6   | Pengguna mengisi email dengan format tidak valid lalu submit                                                              | Sistem menolak submit dan menampilkan pesan validasi format email tidak valid.                                                                                      | Berhasil sesuai hasil yang diharapkan. Validasi email berjalan dengan benar.                                   | Valid      |
| 7   | Pengguna mengubah data profil valid lalu konfirmasi simpan                                                                | Sistem menampilkan modal konfirmasi, setelah disetujui data dikirim ke server, menampilkan notifikasi sukses, keluar dari mode edit, dan menampilkan data terbaru.  | Berhasil sesuai hasil yang diharapkan. Perubahan profil tersimpan dan data profil terbarui.                    | Valid      |
| 8   | Pengguna menekan Batal saat mode edit aktif                                                                               | Sistem membatalkan perubahan lokal, mengembalikan nilai field ke data profil sebelumnya, dan menonaktifkan mode edit.                                               | Berhasil sesuai hasil yang diharapkan. Data kembali ke nilai awal dan mode edit ditutup.                       | Valid      |
| 9   | Pengguna menekan tombol Ubah Password saat semua field password lama, password baru, dan konfirmasi password masih kosong | Sistem menolak submit dan menampilkan pesan validasi wajib isi pada ketiga field password, tanpa menampilkan modal konfirmasi dan tanpa mengirim request ke server. | Berhasil sesuai hasil yang diharapkan. Validasi pada semua field password muncul dan proses tidak dilanjutkan. | Valid      |
| 10  | Pengguna mengisi form ubah password dengan password baru dan konfirmasi password tidak sama                               | Sistem menolak submit dan menampilkan pesan validasi bahwa konfirmasi password tidak sesuai.                                                                        | Berhasil sesuai hasil yang diharapkan. Validasi ketidaksesuaian password muncul.                               | Valid      |
| 11  | Pengguna mengisi password lama dan password baru valid lalu konfirmasi ubah password                                      | Sistem menampilkan modal konfirmasi, setelah disetujui password diperbarui, menampilkan notifikasi sukses, dan form ubah password di-reset.                         | Berhasil sesuai hasil yang diharapkan. Password berhasil diubah dan field form kembali kosong.                 | Valid      |
