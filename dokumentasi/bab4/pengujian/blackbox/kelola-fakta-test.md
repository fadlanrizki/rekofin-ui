# Pengujian Blackbox Fitur Kelola Fakta

Dokumen ini berisi skenario pengujian blackbox untuk fitur kelola fakta pada aplikasi Rekofin UI.

| No  | Bentuk Pengujian                                                                                      | Hasil yang Diharapkan                                                                                                                                                       | Hasil Pengujian                                                                                               | Kesimpulan |
| --- | ----------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------- | ---------- |
| 1   | Admin dengan token valid membuka halaman Kelola Fakta                                                 | Sistem menampilkan halaman Kelola Fakta yang berisi field pencarian, tombol tambah fakta, tabel data fakta, dan pagination.                                                 | Berhasil sesuai hasil yang diharapkan. Seluruh komponen utama halaman tampil.                                 | Valid      |
| 2   | Halaman Kelola Fakta memuat data dari API dengan sukses                                               | Sistem menampilkan daftar fakta beserta nomor, kode, deskripsi, tanggal dibuat, dan aksi yang tersedia.                                                                     | Berhasil sesuai hasil yang diharapkan. Data fakta tampil sesuai respons API.                                  | Valid      |
| 3   | Admin menekan Enter pada field pencarian dengan kata kunci tertentu                                   | Sistem mengirim parameter pencarian dan memperbarui isi tabel berdasarkan hasil data yang dikembalikan.                                                                     | Berhasil sesuai hasil yang diharapkan. Isi tabel berubah mengikuti hasil pencarian.                           | Valid      |
| 4   | Admin berpindah halaman pada pagination data fakta                                                    | Sistem menampilkan data fakta sesuai halaman yang dipilih dan memperbarui isi tabel berdasarkan data halaman tersebut.                                                      | Berhasil sesuai hasil yang diharapkan. Pagination menampilkan data halaman yang benar.                        | Valid      |
| 5   | Data fakta tidak tersedia atau hasil pencarian kosong                                                 | Sistem menampilkan baris informasi Empty Data ... pada tabel tanpa menyebabkan halaman error.                                                                               | Berhasil sesuai hasil yang diharapkan. Empty state tampil dan halaman tetap stabil.                           | Valid      |
| 6   | Admin menekan tombol Fakta untuk menambah data baru                                                   | Sistem mengarahkan admin ke halaman form tambah fakta.                                                                                                                      | Berhasil sesuai hasil yang diharapkan. Halaman form tambah fakta berhasil dibuka.                             | Valid      |
| 7   | Admin mengisi field Kode Fakta, Pertanyaan konsultasi, dan Deskripsi dengan data valid lalu menyimpan | Sistem menampilkan dialog konfirmasi, menyimpan data fakta baru setelah dikonfirmasi, menampilkan notifikasi berhasil, lalu kembali ke halaman daftar fakta.                | Berhasil sesuai hasil yang diharapkan. Data fakta baru berhasil disimpan dan halaman kembali ke daftar fakta. | Valid      |
| 8   | Field Kode Fakta dikosongkan pada form tambah fakta                                                   | Sistem menampilkan pesan validasi Required pada field kode dan data tidak diproses.                                                                                         | Berhasil sesuai hasil yang diharapkan. Validasi field kode tampil.                                            | Valid      |
| 9   | Field Pertanyaan konsultasi dikosongkan pada form tambah fakta                                        | Sistem menampilkan pesan validasi Required pada field pertanyaan dan data tidak diproses.                                                                                   | Berhasil sesuai hasil yang diharapkan. Validasi field pertanyaan tampil.                                      | Valid      |
| 10  | Field Deskripsi dikosongkan pada form tambah fakta                                                    | Sistem menampilkan pesan validasi Required pada field deskripsi dan data tidak diproses.                                                                                    | Berhasil sesuai hasil yang diharapkan. Validasi field deskripsi tampil.                                       | Valid      |
| 11  | Admin membatalkan proses pada dialog konfirmasi simpan fakta                                          | Sistem tidak menyimpan data fakta dan tetap berada pada form tanpa perubahan data di daftar.                                                                                | Berhasil sesuai hasil yang diharapkan. Data tidak tersimpan setelah proses dibatalkan.                        | Valid      |
| 12  | Admin menekan tombol edit pada salah satu data fakta                                                  | Sistem membuka halaman form edit dan menampilkan data fakta yang dipilih pada field form.                                                                                   | Berhasil sesuai hasil yang diharapkan. Data fakta tampil pada form edit.                                      | Valid      |
| 13  | Admin mengubah data fakta yang sudah ada dengan input valid lalu menyimpan                            | Sistem menampilkan dialog konfirmasi, memperbarui data fakta setelah dikonfirmasi, menampilkan notifikasi berhasil, lalu kembali ke halaman daftar fakta.                   | Berhasil sesuai hasil yang diharapkan. Data fakta berhasil diperbarui.                                        | Valid      |
| 14  | Admin menekan tombol hapus pada salah satu data fakta                                                 | Sistem menampilkan dialog konfirmasi penghapusan data fakta.                                                                                                                | Berhasil sesuai hasil yang diharapkan. Dialog konfirmasi hapus tampil.                                        | Valid      |
| 15  | Admin mengonfirmasi penghapusan data fakta                                                            | Sistem menghapus data fakta secara soft delete, menampilkan notifikasi berhasil, lalu memperbarui daftar fakta sehingga data yang dihapus tidak lagi tampil di tabel aktif. | Berhasil sesuai hasil yang diharapkan. Data tidak lagi muncul pada daftar fakta aktif.                        | Valid      |
| 16  | Admin membatalkan dialog konfirmasi hapus data fakta                                                  | Sistem tidak menghapus data fakta dan daftar tetap sama seperti sebelum proses hapus dibatalkan.                                                                            | Berhasil sesuai hasil yang diharapkan. Tidak ada perubahan data setelah pembatalan.                           | Valid      |
| 17  | Admin membuka form edit dengan id fakta yang tidak ditemukan                                          | Sistem menampilkan notifikasi gagal karena data fakta tidak ditemukan dan tidak memproses perubahan data.                                                                   | Berhasil sesuai hasil yang diharapkan. Sistem menolak memuat data fakta yang tidak tersedia.                  | Valid      |
| 18  | Pengguna tanpa token valid atau bukan role ADMIN mengakses fitur Kelola Fakta                         | Sistem menolak akses ke halaman atau endpoint kelola fakta dan mengarahkan pengguna untuk login ulang.                                                                      | Berhasil sesuai hasil yang diharapkan. Fitur hanya dapat diakses oleh admin yang valid.                       | Valid      |
| 19  | Terjadi gangguan server atau jaringan saat mengambil, menyimpan, mengedit, atau menghapus data fakta  | Sistem menampilkan notifikasi gagal, menghentikan proses loading, dan halaman tetap stabil tanpa crash.                                                                     | Berhasil sesuai hasil yang diharapkan. Aplikasi tetap stabil saat terjadi error operasional data fakta.       | Valid      |
