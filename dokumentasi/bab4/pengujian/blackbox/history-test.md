# Pengujian Blackbox Fitur History Konsultasi

Dokumen ini berisi skenario pengujian blackbox untuk fitur history (consultation history) pada aplikasi Rekofin UI.

| No  | Bentuk Pengujian                                                               | Hasil yang Diharapkan                                                                                                                           | Hasil Pengujian                                                                                 | Kesimpulan |
| --- | ------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------- | ---------- |
| 1   | Pengguna role USER membuka halaman history konsultasi (/user/history)          | Sistem menampilkan halaman Riwayat Konsultasi dengan tabel data, field pencarian, tombol Export, dan pagination.                                | Berhasil sesuai hasil yang diharapkan. Komponen utama history tampil dengan baik.               | Valid      |
| 2   | Data history tersedia dan API history berhasil dipanggil                       | Sistem menampilkan daftar history konsultasi pada tabel (rekomendasi, status, tanggal konsultasi, tanggal selesai, aksi detail).                | Berhasil sesuai hasil yang diharapkan. Data history muncul sesuai respons API.                  | Valid      |
| 3   | Data history kosong (tidak ada riwayat)                                        | Sistem menampilkan kondisi empty state pada tabel (Empty Data) dan tidak menampilkan baris data konsultasi.                                     | Berhasil sesuai hasil yang diharapkan. Empty state tampil dengan benar.                         | Valid      |
| 4   | Pengguna melakukan pencarian dengan memasukkan keyword lalu menekan Enter      | Sistem mengirim parameter pencarian, memuat ulang data mulai dari halaman 1, dan menampilkan hasil yang sesuai keyword.                         | Berhasil sesuai hasil yang diharapkan. Filter pencarian bekerja sesuai input.                   | Valid      |
| 5   | Pengguna mengganti halaman melalui pagination                                  | Sistem menampilkan data history sesuai nomor halaman yang dipilih.                                                                              | Berhasil sesuai hasil yang diharapkan. Perpindahan halaman berjalan normal.                     | Valid      |
| 6   | Pengguna menekan tombol Export saat data history tersedia                      | Sistem mengekspor data history ke file CSV dan menampilkan notifikasi sukses export.                                                            | Berhasil sesuai hasil yang diharapkan. File CSV berhasil terunduh dan notifikasi sukses muncul. | Valid      |
| 7   | Pengguna menekan tombol Export saat data history kosong                        | Sistem menolak proses export dan menampilkan notifikasi gagal bahwa data history tidak tersedia untuk diexport.                                 | Berhasil sesuai hasil yang diharapkan. Export dibatalkan dan notifikasi gagal tampil.           | Valid      |
| 8   | Pengguna menekan tombol Lihat Detail (ikon mata) pada salah satu baris history | Sistem mengarahkan pengguna ke halaman detail history sesuai id konsultasi yang dipilih.                                                        | Berhasil sesuai hasil yang diharapkan. Navigasi ke halaman detail history berjalan benar.       | Valid      |
| 9   | Halaman detail history dibuka dengan id valid                                  | Sistem menampilkan detail history konsultasi: tanggal konsultasi, fakta konsultasi, kesimpulan, dan rekomendasi.                                | Berhasil sesuai hasil yang diharapkan. Seluruh informasi detail tampil sesuai data.             | Valid      |
| 10  | Halaman detail history dibuka tanpa id atau id tidak valid                     | Sistem menampilkan pesan error (contoh: ID history tidak ditemukan atau gagal memuat detail) dan menyediakan tombol kembali ke halaman history. | Berhasil sesuai hasil yang diharapkan. Pesan error dan aksi kembali tampil dengan benar.        | Valid      |
| 11  | Pengguna menekan tombol Kembali di halaman detail history                      | Sistem mengarahkan pengguna kembali ke halaman daftar history konsultasi.                                                                       | Berhasil sesuai hasil yang diharapkan. Navigasi kembali ke history berhasil.                    | Valid      |
| 12  | Terjadi gangguan API saat mengambil data list history atau detail history      | Sistem menampilkan notifikasi/pesan error tanpa crash, dan pengguna tetap dapat melanjutkan interaksi yang tersedia.                            | Berhasil sesuai hasil yang diharapkan. Aplikasi tetap stabil pada kondisi error API.            | Valid      |
