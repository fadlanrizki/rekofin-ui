# Pengujian Blackbox Fitur Consultation

Dokumen ini berisi skenario pengujian blackbox untuk fitur consultation pada aplikasi Rekofin UI.

| No  | Bentuk Pengujian                                                                                        | Hasil yang Diharapkan                                                                                                                    | Hasil Pengujian                                                                                        | Kesimpulan |
| --- | ------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------ | ---------- |
| 1   | Pengguna role USER membuka halaman konsultasi (/user/consultation) saat tidak ada konsultasi aktif      | Sistem menampilkan informasi konsultasi dan tombol Mulai Konsultasi.                                                                     | Berhasil sesuai hasil yang diharapkan. Halaman konsultasi tampil normal.                               | Valid      |
| 2   | Pengguna menekan tombol Mulai Konsultasi                                                                | Sistem membuat sesi konsultasi baru dan mengarahkan pengguna ke halaman pertanyaan dengan parameter id konsultasi.                       | Berhasil sesuai hasil yang diharapkan. Redirect ke halaman question dengan id konsultasi berhasil.     | Valid      |
| 3   | Pengguna membuka halaman konsultasi saat masih ada konsultasi berstatus berjalan                        | Sistem otomatis mengecek status konsultasi dan langsung mengarahkan pengguna ke halaman pertanyaan konsultasi yang sedang aktif.         | Berhasil sesuai hasil yang diharapkan. Pengguna diarahkan ke konsultasi aktif tanpa membuat sesi baru. | Valid      |
| 4   | Halaman pertanyaan konsultasi dibuka dengan id konsultasi valid                                         | Sistem menampilkan daftar pertanyaan, progress bar, teks keterangan, serta navigasi Sebelumnya/Selanjutnya.                              | Berhasil sesuai hasil yang diharapkan. Semua elemen utama halaman pertanyaan tampil.                   | Valid      |
| 5   | Pengguna belum menjawab semua pertanyaan                                                                | Tombol Selesai dalam kondisi nonaktif (disabled) sampai seluruh pertanyaan terjawab.                                                     | Berhasil sesuai hasil yang diharapkan. Tombol Selesai tetap nonaktif sebelum semua jawaban diisi.      | Valid      |
| 6   | Pengguna memilih jawaban Ya/Tidak pada pertanyaan                                                       | Jawaban tersimpan pada state pertanyaan aktif dan progress persentase bertambah sesuai jumlah pertanyaan yang sudah diisi.               | Berhasil sesuai hasil yang diharapkan. Nilai jawaban dan progress berubah sesuai interaksi.            | Valid      |
| 7   | Pengguna menekan tombol Selesai setelah semua pertanyaan terjawab                                       | Sistem mengirim payload jawaban ke server, menyelesaikan konsultasi, lalu mengarahkan ke halaman hasil konsultasi dengan id yang sesuai. | Berhasil sesuai hasil yang diharapkan. Submit jawaban sukses dan redirect ke halaman result berjalan.  | Valid      |
| 8   | Halaman hasil konsultasi dibuka dengan id konsultasi valid                                              | Sistem menampilkan ringkasan hasil analisis, daftar kondisi/fakta, kesimpulan, dan rekomendasi tindakan berdasarkan hasil konsultasi.    | Berhasil sesuai hasil yang diharapkan. Data hasil konsultasi tampil sesuai respons server.             | Valid      |
| 9   | Pengguna menekan tombol Buat Konsultasi Baru di halaman hasil                                           | Sistem mengarahkan pengguna kembali ke halaman consultation untuk memulai konsultasi baru.                                               | Berhasil sesuai hasil yang diharapkan. Navigasi ke halaman consultation berhasil.                      | Valid      |
| 10  | Pengguna menekan tombol Selesai & Ke Dashboard di halaman hasil                                         | Sistem mengarahkan pengguna ke dashboard user.                                                                                           | Berhasil sesuai hasil yang diharapkan. Navigasi ke dashboard user berhasil.                            | Valid      |
| 11  | Halaman pertanyaan/hasil diakses tanpa id konsultasi atau id tidak valid                                | Sistem tidak memproses data konsultasi secara normal dan pengguna tidak dapat melanjutkan alur konsultasi hingga id valid tersedia.      | Berhasil sesuai hasil yang diharapkan. Alur konsultasi tidak dapat diteruskan tanpa id valid.          | Valid      |
| 12  | Terjadi kegagalan API saat mulai konsultasi, mengambil pertanyaan, submit jawaban, atau mengambil hasil | Sistem tidak crash, proses berhenti aman, dan pengguna tetap berada pada halaman terkait tanpa perpindahan alur yang tidak valid.        | Berhasil sesuai hasil yang diharapkan. Aplikasi tetap stabil saat terjadi error API.                   | Valid      |
