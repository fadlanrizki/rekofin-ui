# Pengujian Blackbox Fitur User Dashboard

Dokumen ini berisi skenario pengujian blackbox untuk fitur dashboard pengguna pada aplikasi Rekofin UI.

| No  | Bentuk Pengujian                                                             | Hasil yang Diharapkan                                                                                                                                                                          | Hasil Pengujian                                                                                             | Kesimpulan |
| --- | ---------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------- | ---------- |
| 1   | Pengguna berhasil login dengan role USER lalu membuka halaman dashboard user | Sistem menampilkan halaman dashboard user dengan komponen utama: sapaan pengguna, status konsultasi terakhir, ringkasan statistik, kesimpulan terakhir, dan tabel riwayat konsultasi terakhir. | Berhasil sesuai hasil yang diharapkan. Seluruh komponen utama dashboard tampil.                             | Valid      |
| 2   | Dashboard user dimuat saat data berhasil diambil dari API                    | Sistem menampilkan data aktual meliputi total konsultasi, tanggal konsultasi terakhir, status konsultasi terakhir, kesimpulan, dan riwayat konsultasi terbaru.                                 | Berhasil sesuai hasil yang diharapkan. Data tampil sesuai respons API.                                      | Valid      |
| 3   | Dashboard user dimuat saat terjadi gangguan API/response error               | Sistem menampilkan pesan error dan tombol Coba Lagi tanpa menyebabkan halaman crash.                                                                                                           | Berhasil sesuai hasil yang diharapkan. Pesan error tampil dan aplikasi tetap stabil.                        | Valid      |
| 4   | Pengguna menekan tombol Coba Lagi pada kondisi error dashboard               | Sistem memuat ulang proses pengambilan data dashboard. Jika koneksi kembali normal, data dashboard ditampilkan.                                                                                | Berhasil sesuai hasil yang diharapkan. Proses retry berjalan dan data berhasil dimuat ulang.                | Valid      |
| 5   | Status konsultasi terakhir adalah IN_PROGRESS                                | Sistem menampilkan informasi bahwa konsultasi sedang berlangsung dan menampilkan tombol Lanjutkan Konsultasi yang mengarahkan ke halaman pertanyaan konsultasi dengan id konsultasi aktif.     | Berhasil sesuai hasil yang diharapkan. Tombol Lanjutkan Konsultasi mengarah ke halaman question yang benar. | Valid      |
| 6   | Status konsultasi terakhir adalah COMPLETED                                  | Sistem menampilkan informasi konsultasi terakhir selesai, tombol Lihat Hasil Konsultasi ke halaman hasil konsultasi, serta tombol Mulai Konsultasi Baru ke halaman konsultasi.                 | Berhasil sesuai hasil yang diharapkan. Kedua tombol aksi bekerja sesuai tujuan.                             | Valid      |
| 7   | Pengguna belum memiliki konsultasi (lastConsultation kosong)                 | Sistem menampilkan informasi Belum ada konsultasi dan menyediakan tombol Mulai Konsultasi Baru ke halaman konsultasi.                                                                          | Berhasil sesuai hasil yang diharapkan. Informasi dan tombol tampil sesuai kondisi data kosong.              | Valid      |
| 8   | Data kesimpulan tersedia pada konsultasi terakhir                            | Sistem menampilkan daftar kategori kesimpulan, deskripsi, dan informasi jumlah rekomendasi pada tiap item kesimpulan.                                                                          | Berhasil sesuai hasil yang diharapkan. Semua elemen kesimpulan tampil dengan benar.                         | Valid      |
| 9   | Data riwayat konsultasi terbaru tersedia (recentHistories > 0)               | Sistem menampilkan tabel riwayat berisi nomor, tanggal, kesimpulan, status, dan aksi. Untuk status completed, tombol Lihat Detail tersedia dan mengarah ke halaman hasil konsultasi sesuai id. | Berhasil sesuai hasil yang diharapkan. Tabel riwayat tampil dan aksi Lihat Detail berfungsi.                | Valid      |
| 10  | Data riwayat konsultasi terbaru kosong (recentHistories = 0)                 | Sistem menampilkan pesan Belum ada riwayat konsultasi pada area tabel dan tidak menampilkan tombol Lihat Semua Riwayat.                                                                        | Berhasil sesuai hasil yang diharapkan. Tampilan empty state riwayat sesuai.                                 | Valid      |
