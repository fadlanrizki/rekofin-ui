# Pengujian Blackbox Fitur Kelola Kesimpulan

Dokumen ini berisi skenario pengujian blackbox untuk fitur kelola kesimpulan pada aplikasi Rekofin UI.

| No  | Bentuk Pengujian                                                                                     | Hasil yang Diharapkan                                                                                                                              | Hasil Pengujian                                                                                          | Kesimpulan |
| --- | ---------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------- | ---------- |
| 1   | Admin dengan token valid membuka halaman Kelola Kesimpulan                                          | Sistem menampilkan halaman Kelola Kesimpulan yang berisi field pencarian, tombol tambah kesimpulan, tabel data kesimpulan, dan pagination.        | Berhasil sesuai hasil yang diharapkan. Seluruh komponen utama halaman tampil.                           | Valid      |
| 2   | Halaman Kelola Kesimpulan memuat data kesimpulan dari API dengan sukses                              | Sistem menampilkan daftar kesimpulan beserta nomor, kode kesimpulan, kategori, deskripsi, tanggal dibuat, dan aksi yang tersedia.                 | Berhasil sesuai hasil yang diharapkan. Data kesimpulan tampil sesuai respons API.                       | Valid      |
| 3   | Admin menekan Enter pada field pencarian dengan kata kunci kode atau kategori                        | Sistem mengirim parameter pencarian dan memperbarui isi tabel berdasarkan hasil data yang dikembalikan.                                           | Berhasil sesuai hasil yang diharapkan. Isi tabel berubah mengikuti hasil pencarian.                      | Valid      |
| 4   | Admin berpindah halaman pada pagination data kesimpulan                                              | Sistem menampilkan data kesimpulan sesuai halaman yang dipilih dan memperbarui isi tabel berdasarkan data halaman tersebut.                        | Berhasil sesuai hasil yang diharapkan. Pagination menampilkan data halaman yang benar.                   | Valid      |
| 5   | Data kesimpulan tidak tersedia atau hasil pencarian kosong                                           | Sistem menampilkan tabel kosong atau state kosong tanpa menyebabkan halaman error.                                                                 | Berhasil sesuai hasil yang diharapkan. Empty state tampil dan halaman tetap stabil.                      | Valid      |
| 6   | Admin menekan tombol Kesimpulan untuk menambah data baru                                             | Sistem mengarahkan admin ke halaman form tambah kesimpulan.                                                                                        | Berhasil sesuai hasil yang diharapkan. Halaman form tambah kesimpulan berhasil dibuka.                   | Valid      |
| 7   | Admin mengisi kode, kategori, dan deskripsi dengan data valid lalu menyimpan                         | Sistem menampilkan dialog konfirmasi, menyimpan data kesimpulan baru setelah dikonfirmasi, menampilkan notifikasi berhasil, lalu kembali ke daftar. | Berhasil sesuai hasil yang diharapkan. Data kesimpulan baru berhasil disimpan dan halaman kembali ke daftar. | Valid      |
| 8   | Field Kode Kesimpulan dikosongkan pada form tambah kesimpulan                                        | Sistem menampilkan pesan validasi Required pada field kode dan data tidak diproses.                                                                | Berhasil sesuai hasil yang diharapkan. Validasi field kode tampil.                                       | Valid      |
| 9   | Field Kategori dikosongkan pada form tambah kesimpulan                                               | Sistem menampilkan pesan validasi Required pada field kategori dan data tidak diproses.                                                            | Berhasil sesuai hasil yang diharapkan. Validasi field kategori tampil.                                   | Valid      |
| 10  | Field Deskripsi dikosongkan pada form tambah kesimpulan                                              | Sistem menampilkan pesan validasi Required pada field deskripsi dan data tidak diproses.                                                           | Berhasil sesuai hasil yang diharapkan. Validasi field deskripsi tampil.                                  | Valid      |
| 11  | Admin membatalkan proses pada dialog konfirmasi simpan kesimpulan                                    | Sistem tidak menyimpan data kesimpulan dan tetap berada pada form tanpa perubahan data di daftar.                                                  | Berhasil sesuai hasil yang diharapkan. Data tidak tersimpan setelah proses dibatalkan.                   | Valid      |
| 12  | Admin menekan tombol edit pada salah satu data kesimpulan                                            | Sistem membuka halaman form edit dan menampilkan data kesimpulan yang dipilih pada field form.                                                     | Berhasil sesuai hasil yang diharapkan. Data kesimpulan tampil pada form edit.                            | Valid      |
| 13  | Admin mengubah data kesimpulan yang sudah ada dengan input valid lalu menyimpan                       | Sistem menampilkan dialog konfirmasi, memperbarui data kesimpulan setelah dikonfirmasi, menampilkan notifikasi berhasil, lalu kembali ke daftar.  | Berhasil sesuai hasil yang diharapkan. Data kesimpulan berhasil diperbarui.                              | Valid      |
| 14  | Admin menekan tombol hapus pada salah satu data kesimpulan                                            | Sistem menampilkan dialog konfirmasi penghapusan data kesimpulan.                                                                                  | Berhasil sesuai hasil yang diharapkan. Dialog konfirmasi hapus tampil.                                   | Valid      |
| 15  | Admin mengonfirmasi penghapusan data kesimpulan                                                       | Sistem menghapus data kesimpulan, menampilkan notifikasi berhasil, lalu memperbarui daftar kesimpulan sehingga data yang dihapus tidak lagi tampil. | Berhasil sesuai hasil yang diharapkan. Data tidak lagi muncul pada daftar kesimpulan aktif.              | Valid      |
| 16  | Admin membatalkan dialog konfirmasi hapus data kesimpulan                                             | Sistem tidak menghapus data kesimpulan dan daftar tetap sama seperti sebelum proses hapus dibatalkan.                                               | Berhasil sesuai hasil yang diharapkan. Tidak ada perubahan data setelah pembatalan.                       | Valid      |
| 17  | Admin membuka form edit dengan id kesimpulan yang tidak ditemukan                                     | Sistem menampilkan notifikasi gagal karena data kesimpulan tidak ditemukan dan tidak memproses perubahan data.                                      | Berhasil sesuai hasil yang diharapkan. Sistem menolak memuat data kesimpulan yang tidak tersedia.         | Valid      |
| 18  | Pengguna tanpa token valid atau bukan role ADMIN mengakses fitur Kelola Kesimpulan                   | Sistem menolak akses ke halaman atau endpoint kelola kesimpulan dan mengarahkan pengguna untuk login ulang.                                         | Berhasil sesuai hasil yang diharapkan. Fitur hanya dapat diakses oleh admin yang valid.                   | Valid      |
| 19  | Terjadi gangguan server atau jaringan saat mengambil, menyimpan, mengedit, atau menghapus kesimpulan | Sistem menampilkan notifikasi gagal, menghentikan proses loading, dan halaman tetap stabil tanpa crash.                                           | Berhasil sesuai hasil yang diharapkan. Aplikasi tetap stabil saat terjadi error operasional data kesimpulan. | Valid      |
