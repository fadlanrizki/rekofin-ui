# Pengujian Blackbox Fitur Login Admin

Dokumen ini berisi skenario pengujian blackbox untuk fitur login admin pada aplikasi Rekofin UI.

| No  | Bentuk Pengujian                                                                      | Hasil yang Diharapkan                                                                                     | Hasil Pengujian                                                        | Kesimpulan |
| --- | ------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------- | ---------- |
| 1   | Login menggunakan username admin valid dan password valid                             | Sistem memverifikasi kredensial, menyimpan token, lalu mengarahkan admin ke dashboard admin.              | Berhasil sesuai harapan. Admin masuk dan diarahkan ke dashboard admin. | Valid      |
| 2   | Login menggunakan email admin valid dan password valid                                | Sistem menerima credential dalam format email, memverifikasi login, lalu mengarahkan ke dashboard admin.  | Berhasil sesuai harapan. Login via email admin berjalan normal.        | Valid      |
| 3   | Login dengan credential admin valid tetapi password salah                             | Sistem menolak autentikasi, menampilkan pesan Invalid Username Or Password, dan tetap di halaman login.   | Berhasil sesuai harapan. Muncul pesan error dan tidak ada redirect.    | Valid      |
| 4   | Login dengan credential yang tidak terdaftar                                          | Sistem menolak autentikasi, menampilkan pesan Invalid Username Or Password, dan tidak menyimpan token.    | Berhasil sesuai harapan. Pengguna tetap di halaman login.              | Valid      |
| 5   | Login dengan akun admin yang statusnya tidak aktif                                    | Sistem menolak login dan menampilkan pesan User is not active, please contact admin.                      | Berhasil sesuai harapan. Login ditolak untuk akun tidak aktif.         | Valid      |
| 6   | Field Username / Email dikosongkan, password diisi                                    | Validasi form menampilkan pesan Required pada field credential dan request login tidak dikirim ke server. | Berhasil sesuai harapan. Validasi field credential tampil.             | Valid      |
| 7   | Field password dikosongkan, Username / Email diisi                                    | Validasi form menampilkan pesan Required pada field password dan request login tidak dikirim ke server.   | Berhasil sesuai harapan. Validasi field password tampil.               | Valid      |
| 8   | Field Username / Email dan password sama-sama kosong                                  | Validasi form menampilkan pesan Required pada kedua field dan proses login dibatalkan.                    | Berhasil sesuai harapan. Kedua pesan validasi muncul.                  | Valid      |
| 9   | Admin sudah login (token valid role ADMIN di localStorage) lalu membuka halaman login | Sistem otomatis mengarahkan admin ke dashboard admin tanpa menampilkan form login.                        | Berhasil sesuai harapan. Redirect otomatis ke dashboard admin terjadi. | Valid      |
| 10  | Terdapat token tidak valid atau kadaluarsa di localStorage lalu membuka halaman login | Sistem tidak melakukan redirect dan tetap menampilkan halaman login untuk autentikasi ulang.              | Berhasil sesuai harapan. Halaman login tetap ditampilkan.              | Valid      |
| 11  | Menekan tombol Login saat server error atau koneksi bermasalah                        | Sistem menampilkan modal error, menghentikan loading, dan aplikasi tetap stabil di halaman login.         | Berhasil sesuai harapan. Error ditampilkan tanpa crash pada UI.        | Valid      |
