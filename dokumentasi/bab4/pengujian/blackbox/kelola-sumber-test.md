# Pengujian Blackbox Fitur Kelola Sumber

Dokumen ini berisi skenario pengujian blackbox untuk fitur kelola sumber pada aplikasi Rekofin UI.

| No  | Bentuk Pengujian                                                                                 | Hasil yang Diharapkan                                                                                                                           | Hasil Pengujian                                                                                          | Kesimpulan |
| --- | ------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------- | ---------- |
| 1   | Admin dengan token valid membuka halaman Kelola Sumber                                           | Sistem menampilkan halaman Kelola Sumber yang berisi field pencarian, tombol tambah sumber, tabel data sumber, dan pagination.                  | Berhasil sesuai hasil yang diharapkan. Seluruh komponen utama halaman tampil.                            | Valid      |
| 2   | Halaman Kelola Sumber memuat data sumber dari API dengan sukses                                  | Sistem menampilkan daftar sumber beserta nomor, nama sumber, deskripsi, tanggal dibuat, dan aksi yang tersedia.                                 | Berhasil sesuai hasil yang diharapkan. Data sumber tampil sesuai respons API.                            | Valid      |
| 3   | Admin menekan Enter pada field pencarian dengan kata kunci nama sumber, penulis, atau penerbit   | Sistem mengirim parameter pencarian dan memperbarui isi tabel berdasarkan hasil data yang dikembalikan.                                         | Berhasil sesuai hasil yang diharapkan. Isi tabel berubah mengikuti hasil pencarian.                      | Valid      |
| 4   | Admin berpindah halaman pada pagination data sumber                                              | Sistem menampilkan data sumber sesuai halaman yang dipilih dan memperbarui isi tabel berdasarkan data halaman tersebut.                         | Berhasil sesuai hasil yang diharapkan. Pagination menampilkan data halaman yang benar.                   | Valid      |
| 5   | Data sumber tidak tersedia atau hasil pencarian kosong                                           | Sistem menampilkan tabel kosong atau state kosong tanpa menyebabkan halaman error.                                                              | Berhasil sesuai hasil yang diharapkan. Empty state tampil dan halaman tetap stabil.                      | Valid      |
| 6   | Admin menekan tombol Sumber untuk menambah data baru                                             | Sistem mengarahkan admin ke halaman form tambah sumber.                                                                                         | Berhasil sesuai hasil yang diharapkan. Halaman form tambah sumber berhasil dibuka.                       | Valid      |
| 7   | Admin mengisi data sumber dengan informasi valid lalu menyimpan                                  | Sistem menampilkan dialog konfirmasi, menyimpan data sumber baru setelah dikonfirmasi, menampilkan notifikasi berhasil, lalu kembali ke daftar. | Berhasil sesuai hasil yang diharapkan. Data sumber baru berhasil disimpan dan halaman kembali ke daftar. | Valid      |
| 8   | Field Nama Sumber dikosongkan pada form tambah sumber                                            | Sistem menampilkan pesan validasi Required pada field nama sumber dan data tidak diproses.                                                      | Berhasil sesuai hasil yang diharapkan. Validasi field nama sumber tampil.                                | Valid      |
| 9   | Field Penulis dikosongkan pada form tambah sumber                                                | Sistem menolak penyimpanan dan menampilkan notifikasi gagal dari server karena data penulis wajib diisi.                                        | Berhasil sesuai hasil yang diharapkan. Data tidak dapat disimpan tanpa penulis.                          | Valid      |
| 10  | Field Jenis Sumber tidak dipilih pada form tambah sumber                                         | Sistem menolak penyimpanan dan menampilkan notifikasi gagal dari server karena jenis sumber wajib dipilih.                                      | Berhasil sesuai hasil yang diharapkan. Data tidak dapat disimpan tanpa jenis sumber.                     | Valid      |
| 11  | Admin membatalkan proses pada dialog konfirmasi simpan sumber                                    | Sistem tidak menyimpan data sumber dan tetap berada pada form tanpa perubahan data di daftar.                                                   | Berhasil sesuai hasil yang diharapkan. Data tidak tersimpan setelah proses dibatalkan.                   | Valid      |
| 12  | Admin menekan tombol edit pada salah satu data sumber                                            | Sistem membuka halaman form edit dan menampilkan data sumber yang dipilih pada field form.                                                      | Berhasil sesuai hasil yang diharapkan. Data sumber tampil pada form edit.                                | Valid      |
| 13  | Admin mengubah data sumber yang sudah ada dengan input valid lalu menyimpan                      | Sistem menampilkan dialog konfirmasi, memperbarui data sumber setelah dikonfirmasi, menampilkan notifikasi berhasil, lalu kembali ke daftar.    | Berhasil sesuai hasil yang diharapkan. Data sumber berhasil diperbarui.                                  | Valid      |
| 14  | Admin menekan tombol hapus pada salah satu data sumber                                           | Sistem menampilkan dialog konfirmasi penghapusan data sumber.                                                                                   | Berhasil sesuai hasil yang diharapkan. Dialog konfirmasi hapus tampil.                                   | Valid      |
| 15  | Admin mengonfirmasi penghapusan data sumber                                                      | Sistem menghapus data sumber, menampilkan notifikasi berhasil, lalu memperbarui daftar sumber sehingga data yang dihapus tidak lagi tampil.     | Berhasil sesuai hasil yang diharapkan. Data tidak lagi muncul pada daftar sumber aktif.                  | Valid      |
| 16  | Admin membatalkan dialog konfirmasi hapus data sumber                                            | Sistem tidak menghapus data sumber dan daftar tetap sama seperti sebelum proses hapus dibatalkan.                                               | Berhasil sesuai hasil yang diharapkan. Tidak ada perubahan data setelah pembatalan.                      | Valid      |
| 17  | Admin membuka form edit dengan id sumber yang tidak ditemukan                                    | Sistem menampilkan notifikasi gagal karena data sumber tidak ditemukan dan tidak memproses perubahan data.                                      | Berhasil sesuai hasil yang diharapkan. Sistem menolak memuat data sumber yang tidak tersedia.            | Valid      |
| 18  | Pengguna tanpa token valid atau bukan role ADMIN mengakses fitur Kelola Sumber                   | Sistem menolak akses ke halaman atau endpoint kelola sumber dan mengarahkan pengguna untuk login ulang.                                         | Berhasil sesuai hasil yang diharapkan. Fitur hanya dapat diakses oleh admin yang valid.                  | Valid      |
| 19  | Terjadi gangguan server atau jaringan saat mengambil, menyimpan, mengedit, atau menghapus sumber | Sistem menampilkan notifikasi gagal, menghentikan proses loading, dan halaman tetap stabil tanpa crash.                                         | Berhasil sesuai hasil yang diharapkan. Aplikasi tetap stabil saat terjadi error operasional data sumber. | Valid      |
