# Pengujian Blackbox Fitur Login

Dokumen ini berisi skenario pengujian blackbox untuk fitur login pada aplikasi Rekofin UI.

| No  | Bentuk Pengujian                                                                   | Hasil yang Diharapkan (expected)                                                                                                         | Hasil Pengujian                                                                       | Kesimpulan |
| --- | ---------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------- | ---------- |
| 1   | Login dengan credential valid (username/email) dan password valid untuk role USER  | Sistem memverifikasi kredensial, menyimpan token, lalu mengarahkan pengguna ke halaman dashboard user.                                   | Berhasil sesuai expected. Pengguna role USER masuk dan diarahkan ke dashboard user.   | Valid      |
| 2   | Login dengan credential valid (username/email) dan password valid untuk role ADMIN | Sistem memverifikasi kredensial, menyimpan token, lalu mengarahkan pengguna ke halaman dashboard admin.                                  | Berhasil sesuai expected. Pengguna role ADMIN masuk dan diarahkan ke dashboard admin. | Valid      |
| 3   | Login dengan credential terdaftar tetapi password salah                            | Sistem menolak autentikasi dan menampilkan pesan kesalahan (invalid credentials/password salah). Pengguna tetap berada di halaman login. | Berhasil sesuai expected. Muncul pesan kesalahan dan tidak terjadi redirect.          | Valid      |
| 4   | Login dengan credential tidak terdaftar                                            | Sistem menolak autentikasi dan menampilkan pesan bahwa akun tidak ditemukan/invalid credentials.                                         | Berhasil sesuai expected. Sistem tidak mengizinkan login.                             | Valid      |
| 5   | Field credential (username/email) dikosongkan, password diisi                      | Sistem melakukan validasi form dan menampilkan pesan wajib isi pada field credential, proses login tidak dikirim ke server.              | Berhasil sesuai expected. Validasi credential muncul.                                 | Valid      |
| 6   | Field password dikosongkan, credential diisi                                       | Sistem melakukan validasi form dan menampilkan pesan wajib isi pada field password, proses login tidak dikirim ke server.                | Berhasil sesuai expected. Validasi password muncul.                                   | Valid      |
| 7   | Field credential dan password sama-sama kosong                                     | Sistem menampilkan validasi wajib isi pada kedua field, tombol submit tidak memproses autentikasi.                                       | Berhasil sesuai expected. Kedua pesan validasi tampil.                                | Valid      |
| 8   | Credential diisi dengan username valid (bukan email) dan password valid            | Sistem menerima input credential dalam bentuk username dan memproses login dengan sukses.                                                | Berhasil sesuai expected. Login menggunakan username dapat dilakukan.                 | Valid      |
| 9   | Credential diisi dengan email valid dan password valid                             | Sistem menerima input credential dalam bentuk email dan memproses login dengan sukses.                                                   | Berhasil sesuai expected. Login menggunakan email dapat dilakukan.                    | Valid      |
| 10  | Menekan tombol login saat koneksi server bermasalah (timeout/error 500)            | Sistem menampilkan pesan gagal login karena gangguan server/jaringan, tanpa crash pada UI, serta pengguna tetap di halaman login.        | Berhasil sesuai expected. Muncul notifikasi error dan aplikasi tetap stabil.          | Valid      |
